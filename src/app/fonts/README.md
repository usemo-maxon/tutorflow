# easy4tutor fonts

Unmodified variable fonts from the official Google Fonts repository, downloaded
2026-09-15. Full character sets include Polish. Each font's SIL Open Font License
is included alongside it.

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Literata: https://github.com/google/fonts/tree/main/ofl/literata

`next/font/local` removes Google Fonts availability from the build process.
Manrope is preloaded for the interface. Literata is not preloaded and is only
used by the public landing/auth compositions.
