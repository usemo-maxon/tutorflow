# TutorFlow — UI/UX audit та refinement

Дата: 7 вересня 2026. Робота виконана в наявному Next.js застосунку. PRODUCT_SPEC_MVP.md, DESIGN_SPEC.md, FRONTEND_SPEC.md та DO_NOT_DO.md залишені без змін. Правила предметної області й зовнішні інтеграції не підмінялися демонстраційною логікою.

## Виконані цикли

1. Аудит усіх наявних розділів → виправлення ієрархії, типографіки, навігації, календаря та форм → реальні desktop/mobile перегляди.
2. Повторна перевірка створення й завершення уроку → компактніший Dzisiaj, контекст вибраного учня, редагування учня, стабільні чернетки → повторні перегляди.
3. Новий акаунт і стресові дані → виправлення переповнення великої групи, порожнього стану, місячного календаря й мобільних платежів → перевірка збереження при відмові мережі та read-only режиму.
4. Клавіатура й фінальне очищення → явне повернення фокуса з діалогів, постійна доступність Undo, багаторядковий план, оновлення часу → повторний build і перевірки.

## Найважливіші зміни

- **Dzisiaj:** компактніший план дня та список уроків до заповнення; доступ до всіх незавершених уроків; зрозумілі учасники групи й кількість оплачених місць; один стартовий сценарій для порожнього акаунта. «Нитка прогресу» тепер обирає пов’язані попередній, поточний і наступний уроки, не підставляючи прострочений урок як майбутній.
- **Календар:** видимі ранні й пізні уроки, керована прокрутка зі сталими заголовками, підказка часу під курсором, створення з клавіатури через кнопку дня, зрозумілі групи та помилки синхронізації. На телефоні доступні день, тиждень, місяць і agenda. Місяць показує навантаження; agenda — недоступний час і статуси Google. Короткі події мають компактне компонування.
- **Створення уроків:** автоматична підстановка параметрів вибраного учня зі збереженням ручних змін; пошук учасників; компактний підсумок вибору; контекст інших уроків дня; необов’язковий план; явний перегляд серії. Перемикання «кілька дат → одна дата» більше не створює прихованих додаткових уроків. Помилки залишають форму відкритою з введеними даними.
- **Учні:** реалізований інтерфейс редагування через наявну серверну дію; збережені ідентичність та історія; належна пробна ціна; менше порожнього простору; планування відкриває календар із вибраним учнем; архівування винесене в додаткові дії.
- **Проведення уроку:** постійно доступний контекст учасника, компактний вибір для великих груп, розгортаний склад групи, окремі результати/оплати/присутність. Довгі теми та пункти плану багаторядкові. Є явні стани чернетки, запису та помилки; форми не скидаються при оновленні кешу. Масштаб перенесення/скасування серії видимий окремо.
- **Платежі й статистика:** узгоджені періоди та підсумки, пошук і статусні фільтри, коректні копійки, доступний мобільний експорт, компактний фінансовий підсумок, відновлення попереднього статусу через Undo. Нульові значення графіка більше не зображаються додатними стовпчиками.
- **Система дизайну:** читабельніший мінімальний розмір тексту, стримані статусні кольори, контрольована ширина контенту, менше декоративних панелей, уніфіковані кнопки та фокус. Консолідовано 41 дубльований базовий CSS-блок, видалено тимчасові скрипти з кореня проєкту.
- **Доступність:** підписи й зв’язки помилок полів, семантика таблиці платежів, aria-pressed для перемикачів, видимий фокус, фокус у мобільному діалозі, Escape і повернення до кнопки-виклику. Помилки та повідомлення з Undo не зникають за таймером.

## Перевірене покриття

| Розділи | Перевірка |
| --- | --- |
| `/`, `/logowanie`, `/rejestracja` | Desktop/mobile render; валідація входу; реєстрація нового локального акаунта; вхід у демо |
| `/odzyskaj-haslo`, `/polityka-prywatnosci`, `/regulamin` | Наявні сторінки, навігація, фактичний стан недоступного reset flow |
| `/app/dzisiaj` | Демо, новий порожній акаунт, список незавершених уроків, адаптивне компонування |
| `/app/kalendarz` | День/тиждень/місяць/agenda, планування вибраного учня, ранні події, скасовані уроки, групи, недоступність, помилки синхронізації |
| `/app/uczniowie`, `/app/uczniowie/[studentId]` | Пошук/фільтри, створення, відкриття редагування, вкладки, довгі імена, великі нотатки, історія після завершення уроку |
| `/app/lekcje/[lessonId]` | Зміна плану, оцінка, присутність, оплата, чернетка, завершення, групове перемикання, read-only |
| `/app/platnosci`, `/app/statystyki` | Періоди, фільтри, порожня вибірка, зміна оплати та Undo, графік, посилання експорту |
| Усі 4 сторінки налаштувань | Профіль, доступність, інтеграції, підписка; desktop/mobile; доступність полів |

Використані viewport: **360×800, 390×844, 768×1024, 1280×800/900**. Перевірено реальний render та DOM-геометрію. Переповнення великої групи було відтворене й усунуте; після виправлення документ поміщається у viewport. Клавіатурою перевірені Tab, Escape та повернення фокуса меню/форми учня.

Стресовий набір: окремий локальний акаунт, 11 учнів (1 архівний), 12 уроків одного дня, група з 8 учнів, 12 пунктів плану, довгі імена/нотатки, суми з копійками, пробна ціна, скасування, недоступний час, failed/deleted Google стани. Синтетичні інтеграційні стани — fixtures, не реальні відповіді Google. Акаунт залишено локально для повторення перевірок; його read-only режим повернуто у вимкнений стан. Контрольний урок, створений аудитом у демо, видалено; попередні записи демо не видалялися.

**Відмова мережі:** локальний dev-сервер зупинено під час редагування контрольного уроку. Запис показав помилку, текст залишився у формі. Після запуску сервера повторний запис завершився успішно; збереження тексту та індивідуальних статусів підтверджене у UI і локальному сховищі.

## Межі та наступні перевірки

- Реальний upload, повний reset password, admin та зовнішні Google/Telegram/PayU flows у цій реалізації відсутні або не налаштовані. Перевірені їхні чесні стани недоступності; це не завершені live integrations.
- Емуляція viewport не замінює Safari/iOS, Android, віртуальну клавіатуру та читач екрана на фізичному пристрої. Наступний QA-прохід має охопити ці середовища та автоматизований axe suite.
- Drag-and-drop перевірений у коді та через серверні правила перенесення, але повний жест мишею/дотиком у фінальному browser pass не відтворювався. Кнопка зміни терміну залишається альтернативою.
- Захист чернетки охоплює звичайні внутрішні посилання, закриття діалогів і вихід зі сторінки. Повне відновлення чернетки після same-document Back/Forward або аварійного закриття вкладки потребує окремого механізму зберігання чернеток.
- Перевірені посилання експорту; вміст завантажених CSV у цьому UI/UX проході не аудитувався.

Застосунок залишено доступним локально на `http://localhost:3000`. Публікація та commit не виконувалися.
